
# FAQ - ProfiV

Questions fréquentes sur l\'utilisation de ProfiV.

## Général

### Qu\'est-ce que ProfiV ?

ProfiV est une plateforme éducative SaaS pour les professeurs et élèves du Maroc, utilisant l\'intelligence artificielle Gemini 2.5 Flash pour générer des exercices conformes au programme du Ministère de l\'Éducation Nationale.

### ProfiV est-il gratuit ?

Oui, ProfiV propose un plan gratuit avec des limitations. Des plans payants sont disponibles pour les professeurs et les élèves qui ont besoin de plus de fonctionnalités.

### ProfiV fonctionne-t-il hors ligne ?

Oui, ProfiV est une PWA (Progressive Web App) qui fonctionne en mode hors ligne. Les exercices générés sont stockés localement et synchronisés automatiquement lorsque vous êtes reconnecté.

## Utilisation

### Comment générer des exercices ?

1. Connectez-vous à votre compte
2. Allez dans l\'onglet "Générateur"
3. Sélectionnez le niveau, la matière, le chapitre et la difficulté
4. Cliquez sur "Générer"
5. Les exercices apparaîtront avec leurs corrections

### Puis-je personnaliser les exercices ?

Oui, vous pouvez :
- Modifier le niveau de difficulté
- Choisir le type d\'exercice
- Sélectionner plusieurs chapitres
- Ajuster le nombre d\'exercices

### Comment exporter les exercices ?

Après avoir généré des exercices :
1. Cliquez sur le bouton "PDF" ou "Word"
2. Le fichier sera téléchargé automatiquement
3. Vous pouvez également imprimer directement depuis le navigateur

### Puis-je réorganiser les exercices ?

Oui, utilisez le drag & drop pour réorganiser l\'ordre des exercices avant l\'export.

## Comptes

### Comment créer un compte ?

1. Cliquez sur "S\'inscrire"
2. Remplissez le formulaire d\'inscription
3. Vérifiez votre email
4. Connectez-vous avec vos identifiants

### Puis-je utiliser ProfiV sans compte ?

Oui, un mode démo est disponible avec des fonctionnalités limitées. Pour profiter de toutes les fonctionnalités, créez un compte.

### Comment réinitialiser mon mot de passe ?

1. Cliquez sur "Mot de passe oublié"
2. Entrez votre email
3. Suivez les instructions reçues par email

## Paiements

### Quels modes de paiement sont acceptés ?

Nous acceptons :
- Cartes de crédit/débit (Visa, MasterCard)
- PayPal
- Virement bancaire (pour les établissements scolaires)

### Comment annuler mon abonnement ?

1. Connectez-vous à votre compte
2. Allez dans "Paramètres" > "Abonnement"
3. Cliquez sur "Annuler l\'abonnement"
4. Suivez les instructions

### Puis-je obtenir un remboursement ?

Les remboursements sont possibles dans les 14 premiers jours suivant l\'achat. Contactez le support pour en faire la demande.

## Technique

### Quels navigateurs sont supportés ?

ProfiV fonctionne sur tous les navigateurs modernes :
- Chrome (recommandé)
- Firefox
- Safari
- Edge

### ProfiV fonctionne-t-il sur mobile ?

Oui, ProfiV est optimisé pour mobile et fonctionne sur Android et iOS.

### Quelle est la configuration minimale requise ?

- Navigateur moderne avec JavaScript activé
- Connexion internet (pour la génération d\'exercices)
- 2 Go de RAM minimum
- Écran de 320x480 pixels minimum

## Données et Confidentialité

### Mes données sont-elles sécurisées ?

Oui, nous utilisons :
- Chiffrement SSL/TLS pour toutes les communications
- Chiffrement des données sensibles
- Conformité RGPD
- Hébergement sécurisé en Europe

### Qui peut voir mes exercices ?

Seuls vous pouvez voir vos exercices générés, sauf si vous les partagez explicitement.

### Puis-je supprimer mon compte et mes données ?

Oui, allez dans "Paramètres" > "Compte" > "Supprimer mon compte". Toutes vos données seront supprimées dans les 30 jours.

## Problèmes Courants

### Les exercices ne se génèrent pas

Vérifiez :
1. Que vous avez une connexion internet
2. Que votre clé API Gemini est valide
3. Que vous n\'avez pas dépassé votre limite quotidienne

### L\'application est lente

1. Vérifiez votre connexion internet
2. Videz le cache de votre navigateur
3. Essayez un autre navigateur
4. Contactez le support si le problème persiste

### Je ne vois pas mes exercices précédents

1. Vérifiez que vous êtes connecté au bon compte
2. Allez dans l\'onglet "Historique"
3. Si le problème persiste, contactez le support
